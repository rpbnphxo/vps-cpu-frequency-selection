## 先看门槛：哪些场景真吃 CPU 主频

Valve 给 CS2 专用服务器的配置写得比较清楚：CPU 最低 2 vCPU，推荐 4 核以上并建议高主频；内存最低 2 GB，推荐 4 GB，装插件建议 8 GB 以上；存储最低 30 GB，推荐 50 到 65 GB；网络要稳定、低延迟、抗 DDoS。

CS2 对单核性能的依赖很重。跑 64 tick 竞技服时 CPU 频率上不去，玩家的体感是“卡”、走位不对、打人有延迟，加核心数量解决不了这个问题。

插件会额外占用大量内存。SourceMod、Metamod 和各类插件装上之后，内存消耗会快速翻倍，10 人服带插件一般建议 8 GB 打底。1 核 1G 的小 VPS 连 Valve 的最低线都过不去，光是内存那一栏就不合格。

同样的单核逻辑也适用于 WordPress 的 PHP 解析、MySQL 查询、编译和 CI 流水线、Discord Bot，以及 Minecraft、Terraria 这类游戏服。

## RGS 和 RCS 差在哪，哪档多数人用不上

## 什么情况下雨云不是最优解

需要境外多机房、免备案加亚太优化线路，或者预算压到 3 美元这个级别，国内游戏云就不是合适的选项了。

拿 Evoxt 做个纯信息对照：2020 年成立的马来西亚商家，自有 ASN（AS149440），后台和工单支持中文，CPU 主频 3.5 GHz 起步、Turbo 最高 6.0 GHz。全球标准区最低的 VM-0.5 是 1 核 / 512 MB / 5 GB，月付 $2.99，4 核 8G 的 VM-4 是 $23.99。香港、日本大阪、马来西亚 Premium 这三个亚太优质区配置和价格不变，月流量减半，比如 VM-1 是 500 GB 而不是 1000 GB。全系含每周自动异地备份、1 Gbps 端口、KVM、IPv4 与 IPv6，Windows Server 不收授权费。短板也明确：工单响应在 4 到 8 小时，亚太机房流量减半，专用服务器只在马来西亚有。

它没有国内节点，也不涉及备案。要做境内低延迟、要备案域名的 CS2 服，这类境外商家帮不上忙。反过来，只要境外机房、不想备案，雨云的国内节点也不是为你准备的。两条产品线服务的是两类人，不存在谁替代谁。
